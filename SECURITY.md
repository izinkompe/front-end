# Kebijakan Keamanan (Security Policy)

Keamanan kode dan privasi data merupakan prioritas utama dalam pengembangan sistem **PanganTani**.

---

| Versi                       | Didukung           |
| :-------------------------- | :----------------- |
| `main` (pengembangan aktif) | :white_check_mark: |
| Rilis pra-lomba             | :white_check_mark: |

---

## Melaporkan Kerentanan Keamanan

Jika Anda menemukan potensi celah atau kerentanan keamanan pada repository ini:

1. **JANGAN** membuat public issue di GitHub.
2. Laporkan secara privat kepada tim inti proyek dengan menyertakan:
   - Deskripsi lengkap celah keamanan yang ditemukan.
   - Langkah-langkah untuk mereproduksi (Proof of Concept).
   - Dampak potensial terhadap sistem atau data pengguna.
3. Tim pengembang akan segera merespons, memvalidasi laporan, dan menyiapkan patch perbaikan sebelum informasi dipublikasikan.
